觀念講解

慢慢讀

1題本要求

  • 答對才進下一題；答錯顯示 Toast「選擇錯誤」，停在同一題。
  • 結算頁要顯示答對題數、錯誤題數。同一題答錯很多次只算 1 題錯誤。
  • 第 10 題答對後進結算頁。
補充
正式版是用陀螺儀游標「停留 3 秒」選答（第 46 堂）。今天先用手指點把流程做完，後面只要把「點」換成「停留」，判斷對錯的程式完全不用改。

2讓 Box 可以點：clickable

Box(
    modifier = Modifier
        .weight(1f)
        .fillMaxSize()
        .background(Color(0xFFE3F2FD), RoundedCornerShape(16.dp))
        .clickable { choose(i) }      // 新增
        .padding(12.dp),
    …

WinForms 是在 Click 事件裡寫程式；Compose 任何元件都能加 Modifier.clickable { }，大括號就是被點時要做的事。

注意
clickable 要放在 padding 前面，整個方塊（含留白）才點得到。

3在 Composable 裡面寫函式

判斷對錯有好幾行，寫在 clickable 裡會很亂。Kotlin 可以在函式裡面再寫一個函式（區域函式），它看得到外面的 q、index、questions：

fun choose(i: Int) {
    if (i != q.answerIndex) {
        // 答錯
        return
    }
    // 答對
    if (index == questions.lastIndex) onFinish() else index++
}
  • i 是被點的選項編號 0～3（第 28 堂的 row * 2 + col）。
  • q.answerIndex 是第 26 堂把 "a"～"d" 轉成的 0～3。
  • 答錯就 return 提早離開，index 不變，所以停在同一題。

4Toast：跳出一行小提示

val context = LocalContext.current     // 放在 QuizScreen 最上面

Toast.makeText(context, "選擇錯誤", Toast.LENGTH_SHORT).show()
  • Toast 需要 context（「現在是哪個 App」），在 Composable 裡用 LocalContext.current 取得。
  • LENGTH_SHORT 約 2 秒；別忘了最後的 .show()，沒寫就不會出現。
WinForms
MessageBox.Show("選擇錯誤");
Compose
Toast.makeText(context, "選擇錯誤",
    Toast.LENGTH_SHORT).show()

差別是 Toast 不用按確定，會自己消失，也不會擋住畫面。

5答錯只算一次：用 Set

如果每答錯一次就 wrong++，同一題錯 3 次就變成 3 題錯誤，不符合題本。解法是把答錯的題目編號放進 Set（集合）—— Set 不會有重複的東西：

val wrongIds = remember { mutableSetOf<String>() }

wrongIds.add(q.qid)     // 同一個 qid 加幾次都只有一個
動作wrongIds 內容size
Q03 答錯{Q03}1
Q03 又答錯{Q03}1
Q07 答錯{Q03, Q07}2

最後：錯誤題數 = wrongIds.size，答對題數 = questions.size - wrongIds.size（「一次就答對」的題數）。

C#
var wrongIds = new HashSet<string>();
wrongIds.Add(q.qid);
Kotlin
val wrongIds = mutableSetOf<String>()
wrongIds.add(q.qid)
補充
wrongIds 用 remember 包著是為了換題重畫時不要被清空。它本身不是 mutableStateOf，因為畫面上不用即時顯示它。

6完整的 QuizScreen

QuizScreen.kt
// 先用「點擊」作答，讓整個流程跑通；之後換成陀螺儀
@Composable
fun QuizScreen(
    allQuestions: List<Question>,
    onExit: () -> Unit,
    onFinish: () -> Unit
) {
    val context = LocalContext.current
    val questions = remember { allQuestions.shuffled().take(10) }
    var index by remember { mutableIntStateOf(0) }
    val q = questions[index]
    var showExit by remember { mutableStateOf(false) }
    val wrongIds = remember { mutableSetOf<String>() }   // 答錯過的題目，一題只算一次

    // 點了第 i 個選項
    fun choose(i: Int) {
        if (i != q.answerIndex) {
            wrongIds.add(q.qid)
            Toast.makeText(context, "選擇錯誤", Toast.LENGTH_SHORT).show()
            return
        }
        if (index == questions.lastIndex) {
            Log.d("GQ", "答對 ${questions.size - wrongIds.size}，錯誤 ${wrongIds.size}")
            onFinish()
        } else {
            index++
        }
    }

    BackHandler { showExit = true }

    Column(Modifier.fillMaxSize()) {
        Row(
            modifier = Modifier.fillMaxWidth().padding(4.dp),
            verticalAlignment = Alignment.CenterVertically
        ) {
            TextButton(onClick = { showExit = true }) { Text("‹ 返回", fontSize = 18.sp) }
            Text("${index + 1}/${questions.size}", fontSize = 20.sp)
        }
        LinearProgressIndicator(
            progress = { (index + 1) / questions.size.toFloat() },
            modifier = Modifier.fillMaxWidth().padding(horizontal = 16.dp)
        )
        Text(
            q.question,
            fontSize = 22.sp,
            modifier = Modifier.fillMaxWidth().padding(24.dp),
            textAlign = TextAlign.Center
        )
        Column(
            modifier = Modifier.fillMaxWidth().weight(1f).padding(16.dp),
            verticalArrangement = Arrangement.spacedBy(12.dp)
        ) {
            for (row in 0..1) {
                Row(Modifier.weight(1f), horizontalArrangement = Arrangement.spacedBy(12.dp)) {
                    for (col in 0..1) {
                        val i = row * 2 + col
                        Box(
                            modifier = Modifier
                                .weight(1f)
                                .fillMaxSize()
                                .background(Color(0xFFE3F2FD), RoundedCornerShape(16.dp))
                                .clickable { choose(i) }
                                .padding(12.dp),
                            contentAlignment = Alignment.Center
                        ) {
                            Text(q.options[i], fontSize = 20.sp, textAlign = TextAlign.Center)
                        }
                    }
                }
            }
        }
    }

    if (showExit) {
        AlertDialog(
            onDismissRequest = { showExit = false },
            title = { Text("確認退出") },
            text = { Text("確定要退出答題嗎？本局不會保存。") },
            confirmButton = { TextButton(onClick = onExit) { Text("退出") } },
            dismissButton = { TextButton(onClick = { showExit = false }) { Text("取消") } }
        )
    }
}
