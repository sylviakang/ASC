觀念講解

慢慢讀

1三種排版容器

WinForms 用座標（Location）放元件，或用 FlowLayoutPanel、TableLayoutPanel 自動排。Compose 主要用三個容器：

容器排列方式像 WinForms 的
Column由上往下排FlowLayoutPanel（FlowDirection = TopDown）
Row由左往右排FlowLayoutPanel（LeftToRight）
Box疊在一起（後寫的在上面）Panel 裡的元件重疊
Column {
    Text("第一行")
    Text("第二行")
}

Row {
    Text("左")
    Text("右")
}

Box {
    Text("底下")
    Text("上面")   // 會蓋在「底下」上
}

2對齊：Alignment

容器裡的元件靠哪一邊。Column 管水平對齊，Row 管垂直對齊：

Column(horizontalAlignment = Alignment.CenterHorizontally) {
    Text("置中")
    Text("也置中")
}

Row(verticalAlignment = Alignment.CenterVertically) {
    Text("返回")
    Text("1/10")
}

Box(contentAlignment = Alignment.Center) {
    Text("正中央")
}
小技巧
記法：Column 是直的，所以它能決定的是「橫向」靠哪邊；Row 相反。

3間距分配：Arrangement

另一個方向（Column 的垂直、Row 的水平）用 Arrangement 決定元件之間怎麼分配空間：

寫法效果
Arrangement.Top／Start（預設）全部擠在開頭
Arrangement.Center全部擠在中間
Arrangement.SpaceBetween頭尾貼邊，中間平均分
Arrangement.spacedBy(12.dp)每兩個元件之間固定 12dp
Column(
    modifier = Modifier.fillMaxSize(),
    horizontalAlignment = Alignment.CenterHorizontally,
    verticalArrangement = Arrangement.Center
) {
    Text("Gyro Quiz")
    Text("新遊戲")
    Text("遊玩紀錄")
}
補充
要讓 Column 在整個畫面置中，它自己要先 fillMaxSize() 撐滿畫面，否則它只有內容那麼大，置中也看不出來。

4Spacer：空白

兩個元件之間想留一段空白，放一個 Spacer：

Column {
    Text("Gyro Quiz")
    Spacer(Modifier.height(48.dp))
    Text("新遊戲")
}

Row {
    Text("返回")
    Spacer(Modifier.weight(1f))   // 把後面的推到最右邊
    Text("00:15")
}

weight(1f) 的意思是「把剩下的空間都佔掉」。GyroQuiz 答題頁上方：左邊是返回和題號，右邊是時間，中間就用它撐開。

5巢狀排版

容器裡可以再放容器。GyroQuiz 的答題頁結構：

結構示意
Column {                         // 整頁由上往下
    Row { 返回  題號  Spacer  時間 }  // 上方列
    進度條
    題目
    Column {                     // 選項區
        Row { 選項0  選項1 }
        Row { 選項2  選項3 }
    }
}

先畫出這種結構，再寫程式，就不容易亂。
