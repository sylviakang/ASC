1Android Studio 是什麼

寫 WinForms 用的是 Visual Studio；寫 Android App 用的是 Android Studio。它一樣有程式編輯器、專案管理、執行按鈕、除錯工具，只是多了兩樣東西：

  • 模擬器（Emulator）：在電腦裡模擬一支 Android 手機，寫好的 App 會安裝到這支「假手機」上執行。
  • Gradle：負責把程式碼、圖片、設定檔打包成 App 的工具。第一次開專案會跑很久，就是 Gradle 在準備。
補充
比賽用的版本是 Android Studio Otter 3 Feature Drop（2025.2.3）。練習時最好用同一版，選單位置才會跟比賽一樣。用 Help → About 可以看版本。

4專案資料夾怎麼看

左邊的專案視窗上方有一個下拉選單，預設是 Android 檢視，它把檔案依「用途」分組，最好找。重要的只有這幾個：

專案結構（Android 檢視）
app
├─ manifests
│   └─ AndroidManifest.xml   ← App 的設定：名稱、圖示、權限、直橫向
├─ kotlin+java
│   └─ tw.mad08.hello
│       ├─ MainActivity.kt   ← 程式從這裡開始，等於 Program.cs
│       └─ ui.theme          ← 顏色與字型主題（範本產生，先不用動）
└─ res
    ├─ drawable              ← 圖片放這裡（logo.png）
    ├─ mipmap               ← App 圖示
    └─ values
        └─ strings.xml       ← 文字資源，App 名稱在這裡
Gradle Scripts
└─ build.gradle.kts (Module :app)  ← 套件與版本設定
小技巧
切到 Project 檢視會看到真正的資料夾結構，例如 app/src/main/assets。之後放 Questions.json 時會用到。

5第一次看 MainActivity.kt

範本已經寫好一個會顯示「Hello Android!」的程式。今天先不用懂每一行，只要知道三個位置：

MainActivity.kt（範本）
class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {   // ① App 開啟時執行
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {                                        // ② 這裡面就是畫面
            HelloComposeTheme {
                Scaffold(modifier = Modifier.fillMaxSize()) { innerPadding ->
                    Greeting(
                        name = "Android",                   // ③ 改這裡，畫面的字就會變
                        modifier = Modifier.padding(innerPadding)
                    )
                }
            }
        }
    }
}

onCreate 相當於 WinForms 的 Form1_Load：App 一打開就執行。setContent { } 大括號裡寫的東西就是使用者看到的畫面。

6模擬器

右邊工具列的 Device Manager（手機圖示）可以看到已經建立的虛擬裝置。按 ▶ 啟動，第一次開機要 1～2 分鐘。之後按上方的綠色 Run，Android Studio 會自動把 App 裝到模擬器上並打開。

補充
比賽環境只有區網，不能下載新的系統映像檔。練習時用教室電腦已經建立好的模擬器就好，不要自己刪掉重建。
小技巧
模擬器開著就不要關，下次 Run 會快很多。

7一定要記住的快速鍵

按鍵功能
Shift + F10執行（Run）
Alt + Enter紅字時顯示修正建議（最常用：自動加 import）
Ctrl + Space自動完成
Ctrl + Alt + L整理縮排
Ctrl + /註解或取消註解這一行
Ctrl + D複製這一行
Ctrl + S存檔（Android Studio 會自動存，按了也無妨）

跟著做

一步一步

每一步做完都執行一次，確認結果和講義一樣再往下。

01

確認 Android Studio 版本

開啟 Android Studio，選單 Help → About，確認版本是 Otter 3 Feature Drop 2025.2.3。

完成後看到版本號，記在筆記本上。
02

建立第一個專案

File → New → New Project → Phone and Tablet → Empty Activity → Next。

Name 填 HelloCompose，Package name 改成 tw.mad08.hello，按 Finish。

完成後左邊專案視窗出現 app 資料夾，MainActivity.kt 自動打開。
03

認識資料夾

在左邊專案視窗展開 app，對照上面「專案資料夾怎麼看」，逐一點開 AndroidManifest.xml、MainActivity.kt、res/values/strings.xml。

在 strings.xml 找到 app_name，看看它的值是什麼。

完成後strings.xml 裡有 <string name="app_name">HelloCompose</string>。
04

啟動模擬器並執行

打開 Device Manager，啟動一台虛擬裝置。

按上方綠色 ▶ Run（或 Shift + F10）。

完成後模擬器上出現白色畫面，左上角寫著 Hello Android!
05

改一個字再執行

在 MainActivity.kt 找到 name = "Android"，改成自己的名字，例如 name = "小明"。

再按一次 Run。

完成後模擬器上變成 Hello 小明!
06

練快速鍵

把游標放在任一行，依序試 Ctrl + D、Ctrl + /、Ctrl + Alt + L，觀察有什麼變化。最後用 Ctrl + Z 還原。

先看過

遇到問題先對照這張表。

現象原因怎麼修
按 Run 是灰色的Gradle 還在跑，或沒有選裝置等右下角進度跑完；上方裝置選單選一台模擬器
Gradle Sync 失敗比賽環境離線，需要的套件沒有快取請教練處理；File → Settings → Gradle 勾 Offline mode 再 Sync
模擬器一直黑畫面還在開機等 1～2 分鐘；仍不行就在 Device Manager 選 Cold Boot
改了字但畫面沒變沒有重新 Run改完要再按一次 Run
找不到 MainActivity.kt專案視窗不是 Android 檢視左上下拉選單切回 Android
