觀念講解

慢慢讀

1先畫草圖

寫版面之前，先在紙上把答題頁切成四塊，由上往下：

  1. 上方列：‹ 返回、題號 3/10，右邊之後放經過時間 → 一個 Row。
  2. 進度條：一條橫線，答到第幾題就填多滿 → LinearProgressIndicator。
  3. 題目：置中的大字 → Text。
  4. 四個選項：2 列 × 2 欄的大方塊，占掉剩下全部高度 → Column 裡放兩個 Row，每個 Row 放兩個 Box。
小技巧
WinForms 是用滑鼠把控制項拖到位置上；Compose 是「一層一層包」。先想清楚「誰在誰裡面」，程式碼自然就出來了。

2上方列：Spacer(weight) 把東西推到右邊

Row(verticalAlignment = Alignment.CenterVertically) {
    TextButton(…) { Text("‹ 返回") }
    Text("3/10")
    Spacer(Modifier.weight(1f))   // 吃掉中間所有空間
    Text("00:12")                 // 於是被推到最右邊
}

weight(1f) 的意思是「把剩下的空間分給我」。Spacer 本身看不見，它只是把後面的元件擠到右邊。第 31 堂會在這裡放時間，今天先留著 Spacer。

3進度條

LinearProgressIndicator(
    progress = { (index + 1) / questions.size.toFloat() },
    modifier = Modifier.fillMaxWidth()
)
  • progress 要的是 0～1 的小數，第 3 題就是 3/10 = 0.3。
  • questions.size.toFloat() 很重要：3 / 10 兩個都是 Int，結果是 0（整數除法，C# 也一樣）。其中一個轉成 Float 才會得到 0.3。
  • progress 寫成 { … }（lambda），這是新版 Material3 的寫法。
注意
如果寫成 progress = (index + 1) / questions.size，會出現型別錯誤；寫成 { (index + 1) / questions.size } 進度條會一直是空的。

4題目：置中與留白

Text(
    q.question,
    fontSize = 22.sp,
    modifier = Modifier.fillMaxWidth().padding(24.dp),
    textAlign = TextAlign.Center
)

文字要置中，Text 本身必須先 fillMaxWidth() 變得和螢幕一樣寬，textAlign 才有作用（不然 Text 只有字那麼寬，置中也看不出來）。

52×2 選項：weight 讓四格一樣大

這是今天最重要的部分。結構是：

結構
Column(Modifier.weight(1f))        // 占掉剩下的高度
├─ Row(Modifier.weight(1f))       // 上半
│   ├─ Box(weight 1f)  A
│   └─ Box(weight 1f)  B
└─ Row(Modifier.weight(1f))       // 下半
    ├─ Box(weight 1f)  C
    └─ Box(weight 1f)  D
  • 外層 Column 的 weight(1f)：上方列、進度條、題目先量好自己的高度，剩下的全部給選項區。
  • 兩個 Row 都是 weight(1f)：上下各一半。
  • 每個 Box 都是 weight(1f)：左右各一半，再 fillMaxSize() 撐滿那一格。
  • spacedBy(12.dp)：格子之間留 12dp 的縫。

用兩層 for 產生四格，i = row * 2 + col 換算成 0～3：

這個 i 和 q.options[i]、q.answerIndex 是同一套編號，第 29 堂判斷對錯就靠它。

6圓角背景

Modifier
    .background(Color(0xFFE3F2FD), RoundedCornerShape(16.dp))
    .padding(12.dp)

Color(0xFFE3F2FD)：0xFF 是不透明，後面 E3F2FD 是淡藍色（和網頁色碼一樣）。今天先全部同一個顏色，第 30 堂換成隨機顏色。

注意
Modifier 順序有差（第 15 堂）：background 要在 padding 前面，背景才會包含留白；反過來背景會縮在內側。

7今天的完整 QuizScreen

QuizScreen.kt
@Composable
fun QuizScreen(allQuestions: List<Question>, onExit: () -> Unit, onFinish: () -> Unit) {
    val questions = remember { allQuestions.shuffled().take(10) }
    var index by remember { mutableIntStateOf(0) }
    val q = questions[index]
    var showExit by remember { mutableStateOf(false) }
    BackHandler { showExit = true }

    Column(Modifier.fillMaxSize()) {
        // ① 上方列：返回、題號，右邊之後放時間
        Row(
            modifier = Modifier.fillMaxWidth().padding(4.dp),
            verticalAlignment = Alignment.CenterVertically
        ) {
            TextButton(onClick = { showExit = true }) { Text("‹ 返回", fontSize = 18.sp) }
            Text("${index + 1}/${questions.size}", fontSize = 20.sp)
            Spacer(Modifier.weight(1f))
            // 第 31 堂在這裡放時間
        }
        // ② 進度條
        LinearProgressIndicator(
            progress = { (index + 1) / questions.size.toFloat() },
            modifier = Modifier.fillMaxWidth().padding(horizontal = 16.dp)
        )
        // ③ 題目
        Text(
            q.question,
            fontSize = 22.sp,
            modifier = Modifier.fillMaxWidth().padding(24.dp),
            textAlign = TextAlign.Center
        )
        // ④ 2×2 選項：占滿剩下的高度
        Column(
            modifier = Modifier.fillMaxWidth().weight(1f).padding(16.dp),
            verticalArrangement = Arrangement.spacedBy(12.dp)
        ) {
            for (row in 0..1) {
                Row(Modifier.weight(1f), horizontalArrangement = Arrangement.spacedBy(12.dp)) {
                    for (col in 0..1) {
                        val i = row * 2 + col
                        Box(
                            modifier = Modifier
                                .weight(1f)
                                .fillMaxSize()
                                .background(Color(0xFFE3F2FD), RoundedCornerShape(16.dp))
                                .padding(12.dp),
                            contentAlignment = Alignment.Center
                        ) {
                            Text(q.options[i], fontSize = 20.sp, textAlign = TextAlign.Center)
                        }
                    }
                }
            }
        }
        // 暫時的下一題按鈕（第 29 堂拿掉）
        Button(
            onClick = { if (index == questions.lastIndex) onFinish() else index++ },
            modifier = Modifier.align(Alignment.CenterHorizontally).padding(8.dp)
        ) { Text("下一題") }
    }

    if (showExit) { /* 第 24 堂的 AlertDialog，保留不動 */ }
}

需要的 import 很多，紅字時把游標放上去按 Alt+Enter 逐一加入。注意 Color 要選 androidx.compose.ui.graphics.Color。
