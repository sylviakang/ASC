Android 會通知 App 現在的狀態，常用的有：

3監聽生命週期：DisposableEffect

val lifecycleOwner = LocalLifecycleOwner.current
DisposableEffect(lifecycleOwner) {
    val observer = LifecycleEventObserver { _, event ->
        if (event == Lifecycle.Event.ON_RESUME) resumed = true
        if (event == Lifecycle.Event.ON_PAUSE) resumed = false
    }
    lifecycleOwner.lifecycle.addObserver(observer)
    onDispose { lifecycleOwner.lifecycle.removeObserver(observer) }
}
  • LocalLifecycleOwner.current：拿到「目前這個 Activity 的生命週期」。
  • LifecycleEventObserver { _, event -> … }：一個 lambda，每次狀態改變就被呼叫，event 是哪個事件。_ 表示第一個參數用不到。
  • DisposableEffect 和 LaunchedEffect 很像，畫面出現時執行；差別是它一定要寫 onDispose，畫面消失時把監聽取消。
C# 事件
this.Activated += OnActivated;
// 關閉時
this.Activated -= OnActivated;
Compose
lifecycle.addObserver(observer)
onDispose {
    lifecycle.removeObserver(observer) }
注意
沒有 onDispose 取消監聽，離開答題頁之後 observer 還留著，這叫「記憶體洩漏」。第 38 堂的陀螺儀也是一樣的寫法，今天先熟悉。

4LaunchedEffect 的 key：值改變就重新開始

上一堂寫 LaunchedEffect(Unit)，Unit 永遠不變，所以只跑一次。現在改成 LaunchedEffect(resumed)：

  1. resumed 從 true 變 false → 正在跑的 while 迴圈被自動取消。
  2. 新的一次開始執行，第一行 if (!resumed) return@LaunchedEffect 直接結束 → 計時停止。
  3. resumed 變回 true → 又被取消再重新開始，last 重新取現在時間，背景那段時間不會被加進去。
補充
return@LaunchedEffect 是「從這個 LaunchedEffect 的大括號離開」。只寫 return 會以為是離開整個 QuizScreen，編譯器不允許。

這就是為什麼上一堂要用 elapsedMs 累加：停止時累加的值還在，重新開始時從那裡繼續加。

5完整的計時區塊

QuizScreen.kt
var elapsedMs by remember { mutableLongStateOf(0L) }
var resumed by remember { mutableStateOf(true) }      // App 是否在前景

val lifecycleOwner = LocalLifecycleOwner.current
DisposableEffect(lifecycleOwner) {
    val observer = LifecycleEventObserver { _, event ->
        if (event == Lifecycle.Event.ON_RESUME) resumed = true
        if (event == Lifecycle.Event.ON_PAUSE) resumed = false
    }
    lifecycleOwner.lifecycle.addObserver(observer)       // 開始監聽
    onDispose { lifecycleOwner.lifecycle.removeObserver(observer) }   // 離開時取消
}

LaunchedEffect(resumed) {
    if (!resumed) return@LaunchedEffect                 // 在背景：什麼都不做
    var last = System.currentTimeMillis()
    while (true) {
        delay(100)
        val now = System.currentTimeMillis()
        elapsedMs += now - last
        last = now
    }
}

import 時注意：LocalLifecycleOwner 選 androidx.lifecycle.compose（新版）或 androidx.compose.ui.platform（舊版），兩個都能用，選有出現的那個。Lifecycle、LifecycleEventObserver 是 androidx.lifecycle。
