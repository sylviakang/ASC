觀念講解

慢慢讀

1函式的寫法

C#
int Add(int a, int b)
{
    return a + b;
}
Kotlin
fun add(a: Int, b: Int): Int {
    return a + b
}
  • 開頭寫 fun。
  • 參數是「名字: 型別」，和變數一樣型別在後。
  • 回傳型別寫在括號後面，用冒號隔開。
  • Kotlin 函式名稱習慣小寫開頭（add），C# 是大寫（Add）。

2沒有回傳值

C# 寫 void；Kotlin 不寫回傳型別就好（其實是 Unit）。

C#
void SayHi(string name)
{
    Console.WriteLine("Hi " + name);
}
Kotlin
fun sayHi(name: String) {
    println("Hi $name")
}

3單行函式

函式內容只有一個 return 時，可以用 = 寫成一行，回傳型別也能省略：

fun add(a: Int, b: Int): Int = a + b
fun square(x: Int) = x * x
fun isPass(score: Int) = score >= 60
小技巧
GyroQuiz 的小工具函式大多寫成這樣，例如 fun clamp(v: Float, min: Float, max: Float): Float = …。

4預設參數與具名參數

參數可以給預設值，呼叫時就能省略。呼叫時也可以寫參數名字，順序就不重要了：

fun progress(elapsedMs: Long, totalMs: Long = 3000): Float =
    elapsedMs.toFloat() / totalMs

println(progress(1500))            // 0.5（totalMs 用預設 3000）
println(progress(1500, 5000))      // 0.3
println(progress(totalMs = 2000, elapsedMs = 1000))  // 0.5
補充
Compose 的畫面元件大量使用具名參數，例如 Text(text = "Hi", fontSize = 20.sp)。先熟悉這種寫法。

5函式放在哪裡

Kotlin 的函式可以直接寫在檔案最外層，不用包在 class 裡。main 也是這樣的函式。同一個專案、同一個套件裡的函式可以互相呼叫，不用 import。

fun formatClock(sec: Int): String {
    val m = (sec / 60).toString().padStart(2, '0')
    val s = (sec % 60).toString().padStart(2, '0')
    return "$m:$s"
}

fun main() {
    println(formatClock(75))   // 01:15
}
