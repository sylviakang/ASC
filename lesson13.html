第 13 堂Compose 畫面基礎

從 WinForms 到 Compose

從這堂開始做畫面。WinForms 是把元件拖到表單上，再用程式改它的屬性；Compose 完全不同：畫面是一個函式，給它資料就畫出對應的樣子。這堂先建立觀念，寫出第一個 Composable 函式，並學會用 Preview 預覽。

1兩種做畫面的方式

在 WinForms，你從工具箱把 Label 拖到 Form 上，然後在事件裡改它：label1.Text = "答對";。這叫命令式：你一步一步命令元件改變。

Compose 是宣告式：你寫一個函式，描述「現在的資料應該長成什麼畫面」。資料一變，Compose 會自動重新呼叫這個函式，畫面就更新了。你不會去找某個元件來改它的屬性。

WinForms
// WinForms：拖一個 Label，再用程式改它
private void button1_Click(object sender, EventArgs e)
{
    label1.Text = "答對";
}
Compose
// Compose：畫面是函式，參數決定長相
@Composable
fun ResultText(ok: Boolean) {
    Text(if (ok) "答對" else "答錯")
}
補充
先記住這句話：畫面 = 函式(資料)。後面每一堂都在練這個想法。

2@Composable 函式

畫面的函式前面要加 @Composable。它和一般函式有三個不同：

  • 函式名稱大寫開頭（HomeScreen、ResultText），像 C# 的類別名稱。
  • 沒有回傳值，它「發出」畫面元件，而不是 return。
  • 只能在另一個 @Composable 函式裡呼叫，或在 setContent { } 裡呼叫。
@Composable
fun Hello() {
    Text("Hello Compose")
}

3setContent：畫面的起點

MainActivity 的 setContent { } 裡呼叫的那個函式，就是 App 打開時看到的畫面。範本的程式有很多我們暫時用不到的東西，從今天起改成這個簡單的版本：

MainActivity.kt
package tw.mad08.compose

import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.activity.enableEdgeToEdge
import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.foundation.layout.safeDrawingPadding
import androidx.compose.material3.Surface
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            Surface(modifier = Modifier.fillMaxSize().safeDrawingPadding()) {
                Hello()
            }
        }
    }
}

@Composable
fun Hello() {
    Text("Hello Compose")
}
  • Surface：一張鋪滿畫面的底紙，讓背景是白色。
  • fillMaxSize()：填滿整個螢幕。
  • safeDrawingPadding()：避開上方狀態列和下方導覽列，內容才不會被擋住。
小技巧
這幾行先照抄就好，Modifier 在第 15 堂詳細教。

4Text：顯示文字

Text 相當於 WinForms 的 Label。最簡單的用法只要給文字：

Text("Gyro Quiz")
Text(text = "Gyro Quiz")   // 具名參數，意思一樣

一個函式裡寫兩個 Text，它們會疊在同一個位置，因為還沒告訴 Compose 要怎麼排。下一堂學排版。

5import 與 Alt + Enter

每一個用到的元件都要 import。打 Text 時出現紅字，把游標放在紅字上按 Alt + Enter → Import。

注意
Text 有兩個同名的選項：androidx.compose.material3.Text 和 androidx.compose.material.Text。永遠選 material3。選錯可能會編譯失敗。

6Preview：不用開模擬器就看到畫面

在函式上面加 @Preview，編輯器右上角切到 Split，右邊就會顯示畫面預覽。改完程式後預覽會自動更新（有時要按一下 Build & Refresh）。

@Preview(showBackground = true)
@Composable
fun HelloPreview() {
    Hello()
}
補充
Preview 只是給你看的，不會出現在 App 裡。比賽時用 Preview 調整排版比每次開模擬器快很多。
