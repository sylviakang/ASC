觀念講解

慢慢讀

1讀檔三步驟

  1. 打開檔案、讀成字串：context.assets.open("Questions.json").bufferedReader().use { it.readText() }
  2. 字串變成 JSON：JSONArray(text)
  3. 一題一題取出來：for 迴圈 + getJSONObject + getString
C#
string text = File.ReadAllText("Questions.json");
Kotlin
val text = context.assets.open("Questions.json")
    .bufferedReader().use { it.readText() }
  • assets.open 打開檔案。
  • bufferedReader() 用文字的方式讀。
  • use { it.readText() } 讀完全部內容，並且自動關閉檔案（像 C# 的 using）。

2JSONArray 與 JSONObject 怎麼用

要做的事寫法
字串變陣列val array = JSONArray(text)
陣列有幾個array.length()（注意是函式，有括號）
取第 i 個物件array.getJSONObject(i)
物件取字串欄位obj.getString("question")
物件取數字欄位obj.getInt("score")
物件取裡面的物件obj.getJSONObject("options")
物件取裡面的陣列obj.getJSONArray("list")
注意
JSONArray 沒有 size，要用 length()；也不能用 for (x in array) 走訪，要用 for (i in 0 until array.length())。

3完整的 loadQuestions

Question.kt（完整）
package tw.mad08.gyroquiz00

import android.content.Context
import org.json.JSONArray

data class Question(
    val qid: String,
    val question: String,
    val options: List<String>,
    val answer: String
) {
    // "a"～"d" 轉成 0～3
    val answerIndex: Int
        get() = "abcd".indexOf(answer)
}

// 讀 assets/Questions.json
fun loadQuestions(context: Context): List<Question> {
    val text = context.assets.open("Questions.json").bufferedReader().use { it.readText() }
    val array = JSONArray(text)
    val list = mutableListOf<Question>()
    for (i in 0 until array.length()) {
        val obj = array.getJSONObject(i)
        val opts = obj.getJSONObject("options")
        list.add(
            Question(
                qid = obj.getString("qid"),
                question = obj.getString("question"),
                options = listOf("a", "b", "c", "d").map { opts.getString(it) },
                answer = obj.getString("answer")
            )
        )
    }
    return list
}
  1. listOf("a", "b", "c", "d").map { opts.getString(it) }：把 a～d 四個欄位依序取出，變成 4 個字串的 List。這是第 11 堂的 map。
  2. 每讀一題就 list.add(Question(…))，最後回傳整個 list。

4在哪裡呼叫

題目只需要讀一次。放在 App.kt 最上層，用 remember 包起來，換頁時就不會重讀：

App.kt
@Composable
fun GyroQuizApp() {
    val context = LocalContext.current
    val allQuestions = remember { loadQuestions(context) }
    var screen by remember { mutableStateOf(Screen.HOME) }
    …
}

然後把 allQuestions 傳給答題頁：

App.kt
Screen.QUIZ -> QuizScreen(
    allQuestions = allQuestions,
    onExit = { screen = Screen.HOME },
    onFinish = { screen = Screen.RESULT }
)

QuizScreen 的宣告也要多一個參數 allQuestions: List<Question>。

5先用 Log 確認讀到了

畫面還沒做之前，先在 QuizScreen 裡印出來看：

Log.d("GQ", "題數 ${allQuestions.size}")

因為 Question 是 data class，第二行會印出所有欄位，一眼就能看出 options 和 answer 對不對。
