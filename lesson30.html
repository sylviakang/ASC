觀念講解

慢慢讀

1題本規則

  1. 同一題的 4 個選項顏色互不相同。
  2. 換下一題時，同一個位置的顏色不能和上一題一樣（A 格上一題是紅，這一題就不能是紅）。
  3. 顏色從自己準備的調色盤隨機挑。
小技巧
這種「規則」最怕看起來對、其實偶爾會錯。所以今天把規則寫成一個不碰畫面的普通函式，再用單元測試跑 500 次證明它沒錯。

3挑顏色的函式

QuizLogic.kt
// 從調色盤挑 4 個不重複的顏色位置，而且每個位置都跟上一題同位置不同
fun nextColorIndexes(paletteSize: Int, previous: List<Int>?, random: Random = Random): List<Int> {
    while (true) {
        val pick = (0 until paletteSize).shuffled(random).take(4)
        if (previous == null || pick.indices.none { pick[it] == previous[it] }) return pick
    }
}

一行一行看：

  1. (0 until paletteSize)：0～7 這 8 個號碼。
  2. .shuffled(random).take(4)：打亂後取 4 個 → 一定互不相同（規則 1）。
  3. previous == null：第 1 題沒有上一題，直接用。
  4. pick.indices.none { pick[it] == previous[it] }：0～3 每個位置都「沒有」和上一題相同 → 規則 2 成立，回傳。
  5. 不成立就 while (true) 再抽一次，直到成功。
C#
while (true) {
    var pick = Enumerable.Range(0, 8)
        .OrderBy(x => rnd.Next()).Take(4).ToList();

Kotlin
while (true) {
    val pick = (0 until 8).shuffled().take(4)
    if (previous == null ||
        pick.indices.none { pick[it] == previous[it] })
        return pick
}
補充
參數 random: Random = Random 有預設值，平常不用給；測試時可以給固定種子 Random(1)，讓每次結果一樣、方便重現。

4單元測試：不用開模擬器就能驗證

單元測試放在 app/src/test/java/你的套件/（注意是 test，不是 androidTest）。專案建立時就有 JUnit，可以直接用。

ColorTest.kt
package tw.mad08.gyroquiz00

import org.junit.Assert.assertEquals
import org.junit.Assert.assertNotEquals
import org.junit.Test
import kotlin.random.Random

class ColorTest {
    @Test
    fun fourColorsAreDifferent() {
        repeat(100) {
            val c = nextColorIndexes(8, null)
            assertEquals(4, c.toSet().size)
        }
    }

    @Test
    fun samePositionNeverRepeats() {
        val random = Random(1)
        var prev = nextColorIndexes(8, null, random)
        repeat(500) {
            val cur = nextColorIndexes(8, prev, random)
            for (i in 0..3) assertNotEquals(prev[i], cur[i])
            prev = cur
        }
    }
}
  • @Test：標記這是一個測試。
  • assertEquals(期望, 實際)：不相等就失敗。
  • c.toSet().size：轉成 Set 去掉重複，還是 4 個 → 4 色都不同。
  • 第二個測試連續挑 500 題，每題檢查 4 個位置都和上一題不同。

執行：在 ColorTest 檔案上按右鍵 → Run 'ColorTest'。下方出現綠色勾勾就是通過。

小技巧
比賽時可以用同樣方法驗證計時格式、碰撞判斷等純計算的函式，比在模擬器上手動測快很多。
