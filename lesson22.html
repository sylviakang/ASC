四個頁面與換頁

GyroQuiz 有 4 頁。Compose 換頁不用開新視窗，而是用一個 Screen 狀態記住「現在在哪一頁」，再用 when 決定要畫哪一頁。這堂把 4 頁的骨架和所有換頁路線接好，首頁的 2 分到手。

頁面enum class Screen { HOME, QUIZ, … }
現在var screen by remember { … }
切換when (screen) { … }

觀念講解

慢慢讀

1WinForms 怎麼換頁、Compose 怎麼換頁

WinForms 換頁通常是 new Form2().Show()，開一個新視窗。Compose 不開新視窗，而是在同一個畫面裡，依狀態決定要畫哪一頁：

var screen by remember { mutableStateOf(Screen.HOME) }

when (screen) {
    Screen.HOME -> HomeScreen(…)
    Screen.QUIZ -> QuizScreen(…)
    …
}

screen 改成 Screen.QUIZ，Compose 重畫，when 就改畫 QuizScreen。這就是第 10 堂的 enum + when，加上第 17 堂的狀態。

補充
Android 也有 Navigation 套件，但比賽不一定能用，而且對這個題目太複雜。enum + when 只用 Compose 內建功能就能完成。

3誰通知誰換頁

每一頁按下按鈕時，呼叫上層傳進來的 lambda，lambda 裡改 screen：

頁面參數做什麼
HomeScreenonNewGamescreen = QUIZ
HomeScreenonRecordsscreen = RECORDS
QuizScreenonExitscreen = HOME（中途退出）
QuizScreenonFinishscreen = RESULT（答完）
ResultScreenonPlayAgainscreen = QUIZ
ResultScreenonHomescreen = HOME
RecordsScreenonBackscreen = HOME

4完整的 App.kt

App.kt
package tw.mad08.gyroquiz00

import androidx.compose.foundation.layout.fillMaxSize
import androidx.compose.foundation.layout.safeDrawingPadding
import androidx.compose.material3.Surface
import androidx.compose.runtime.Composable
import androidx.compose.runtime.getValue
import androidx.compose.runtime.mutableStateOf
import androidx.compose.runtime.remember
import androidx.compose.runtime.setValue
import androidx.compose.ui.Modifier

enum class Screen { HOME, QUIZ, RESULT, RECORDS }

@Composable
fun GyroQuizApp() {
    var screen by remember { mutableStateOf(Screen.HOME) }

    Surface(modifier = Modifier.fillMaxSize().safeDrawingPadding()) {
        when (screen) {
            Screen.HOME -> HomeScreen(
                onNewGame = { screen = Screen.QUIZ },
                onRecords = { screen = Screen.RECORDS }
            )
            Screen.QUIZ -> QuizScreen(
                onExit = { screen = Screen.HOME },
                onFinish = { screen = Screen.RESULT }
            )
            Screen.RESULT -> ResultScreen(
                onPlayAgain = { screen = Screen.QUIZ },
                onHome = { screen = Screen.HOME }
            )
            Screen.RECORDS -> RecordsScreen(onBack = { screen = Screen.HOME })
        }
    }
}

5三個暫時的頁面

答題、結算、紀錄頁還沒做，先寫最簡單的版本，只要有按鈕能換頁就好。之後幾堂會一頁一頁換成正式內容。

QuizScreen.kt（暫時版本）
@Composable
fun QuizScreen(onExit: () -> Unit, onFinish: () -> Unit) {
    Column(Modifier.fillMaxSize().padding(24.dp)) {
        Text("答題頁（之後完成）")
        Button(onClick = onFinish) { Text("假裝答完") }
        Button(onClick = onExit) { Text("退出") }
    }
}
ResultScreen.kt（暫時版本）
@Composable
fun ResultScreen(onPlayAgain: () -> Unit, onHome: () -> Unit) {
    Column(Modifier.fillMaxSize().padding(24.dp)) {
        Text("結算頁（之後完成）")
        Button(onClick = onPlayAgain) { Text("再玩一次") }
        Button(onClick = onHome) { Text("回首頁") }
    }
}
RecordsScreen.kt（暫時版本）
@Composable
fun RecordsScreen(onBack: () -> Unit) {
    Column(Modifier.fillMaxSize().padding(24.dp)) {
        Text("遊玩紀錄（之後完成）")
        Button(onClick = onBack) { Text("返回") }
    }
}
