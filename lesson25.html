觀念講解

慢慢讀

1JSON 是什麼

JSON 是一種「用文字存資料」的格式，人看得懂、程式也好讀。比賽題目常常把題庫、關卡、設定放在 JSON 檔裡給你。

JSON 只有兩種「容器」：

符號名稱像什麼Kotlin 讀取用
[ … ]陣列 ArrayC# 的陣列／List：一排值，用索引 0、1、2 取JSONArray
{ … }物件 ObjectC# 的物件或 Dictionary：用「名稱」取值JSONObject

裡面的值可以是字串 "…"、數字、true/false，或是另一個陣列、物件（一層包一層）。

2讀懂 Questions.json

下面是和題目相同結構的示意（實際內容請打開 assets/Questions.json 看）：

Questions.json 的結構（示意）
[
  {
    "qid": "q001",
    "question": "台灣最高的山是？",
    "options": {
      "a": "雪山",
      "b": "合歡山",
      "c": "玉山",
      "d": "阿里山"
    },
    "answer": "c"
  },
  {
    "qid": "q002",
    "question": "1 公里等於幾公尺？",
    "options": { "a": "10", "b": "100", "c": "1000", "d": "10000" },
    "answer": "c"
  }
]
  1. 最外層是 [ ]：一個陣列，每一個元素是一題。
  2. 每一題是 { }：一個物件，有 4 個欄位：qid、question、options、answer。
  3. options 本身又是一個物件，裡面有 a、b、c、d 四個欄位。
  4. answer 是字母 "a"～"d"，代表正確選項。
小技巧
讀 JSON 的訣竅：從外往內，每遇到一層就問「這是 [ ] 還是 { }？」，決定要用 JSONArray 還是 JSONObject。

3對應到 Kotlin 的 data class

我們要把每一題變成第 9 堂學過的 data class：

data class Question(
    val qid: String,              // "q001"
    val question: String,         // "台灣最高的山是？"
    val options: List<String>,    // ["雪山", "合歡山", "玉山", "阿里山"]
    val answer: String            // "c"
) {
    val answerIndex: Int          // "c" → 2
        get() = "abcd".indexOf(answer)
}

JSON 的 options 是 a～d 的物件，但畫面要用 0～3 的索引排 2×2，所以我們把它轉成 List，順序固定是 a、b、c、d。

4assets 是什麼

assets 資料夾裡的檔案會原封不動被打包進 APK，程式執行時可以用檔名打開讀取，就像讀一般檔案。res/drawable 的圖片則會被 Android 處理、給編號（R.drawable.logo）。

資料夾怎麼取用適合放
res/drawableR.drawable.名稱圖片
assetscontext.assets.open("檔名")JSON、文字檔等要自己讀的檔案

5從畫面拿到 context

要打開 assets 需要 context（App 的「環境」，可以存取資源、系統服務）。在 Composable 裡這樣拿：

val context = LocalContext.current

下一堂讀檔、之後的 Toast、感測器都會用到它。
