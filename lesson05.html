判斷：if 與 when

if 和 C# 幾乎一樣，但 Kotlin 沒有三元運算子 ? :，也沒有 switch。取而代之的是「if 可以當成值」和更好用的 when。GyroQuiz 的換頁、狀態切換全都靠 when。

當成值if (ok) "對" else "錯"
取代 switchwhen (x) { 1 -> … else -> … }

觀念講解

慢慢讀

1if／else 和 C# 一樣

C#
if (score >= 60)
{
    Console.WriteLine("及格");
}
else if (score >= 40)
{
    Console.WriteLine("補考");
}
else
{
    Console.WriteLine("不及格");
}
Kotlin
if (score >= 60) {
    println("及格")
} else if (score >= 40) {
    println("補考")
} else {
    println("不及格")
}

比較運算 == != > < >= <= 和邏輯運算 && || ! 完全一樣。

補充
Kotlin 的習慣是 { 放在同一行結尾，不換行。

2if 可以當成「值」

C# 用三元運算子 條件 ? A : B；Kotlin 沒有 ? :，改用 if 直接產生值：

C#
string result = ok ? "答對" : "答錯";
Kotlin
val result = if (ok) "答對" else "答錯"
小技巧
GyroQuiz 選項邊框的顏色就是這樣寫：val borderColor = if (phase == Phase.WRONG) Color.Red else Color.Green。

3when 取代 switch

Kotlin 沒有 switch，改用 when。不用寫 case 和 break，每一個分支用 ->。

C#
switch (answer)
{
    case "a":
        index = 0;
        break;
    case "b":
        index = 1;
        break;
    default:
        index = -1;
        break;
}
Kotlin
when (answer) {
    "a" -> index = 0
    "b" -> index = 1
    else -> index = -1
}

when 也可以當成值，而且一個分支可以放多個值、也可以放範圍：

val index = when (answer) {
    "a" -> 0
    "b" -> 1
    "c" -> 2
    "d" -> 3
    else -> -1
}

val level = when (score) {
    100 -> "滿分"
    in 80..99 -> "優秀"       // 80 到 99
    in 60..79 -> "及格"
    else -> "加油"
}

4沒有參數的 when

when 後面不寫東西時，每個分支就是一個條件，等於一串 if／else if：

val msg = when {
    seconds < 60 -> "${seconds}s"
    seconds < 3600 -> "${seconds / 60}m ${seconds % 60}s"
    else -> "超過一小時"
}

5多行分支要加大括號

分支裡要做很多事時，用大括號包起來：

when (phase) {
    "WRONG" -> {
        println("選擇錯誤")
        println("鎖定 5 秒")
    }
    "CORRECT" -> println("答對了")
    else -> {}
}
補充
第 47、48 堂的 Phase 狀態機就是一個 when，每個分支處理一種狀態。
