觀念講解

慢慢讀

1Modifier 是什麼

WinForms 元件有一堆屬性：Size、Padding、BackColor、BorderStyle。Compose 把這些「外觀與大小」的設定集中到一個參數：modifier。幾乎每個元件都有這個參數。

Text(
    text = "新遊戲",
    modifier = Modifier
        .padding(16.dp)
        .background(Color.Yellow)
)

Modifier 後面用點一個接一個串起來，每一個點都是一個設定。

2大小

寫法意思
.size(160.dp)寬高都 160dp
.width(220.dp)／.height(48.dp)只設寬或高
.fillMaxWidth()寬度撐滿父容器
.fillMaxHeight()高度撐滿
.fillMaxSize()寬高都撐滿
.weight(1f)在 Row/Column 裡分配剩餘空間（只能在 Row/Column 的子元件用）
補充
dp 是和螢幕密度無關的單位，同樣 160dp 在大小手機上看起來差不多大。文字大小用 sp（下一堂）。

3weight：平均分配

Row 裡兩個元件都設 weight(1f)，就會各佔一半。GyroQuiz 的 2×2 選項就是這樣做的：

Row(Modifier.fillMaxWidth()) {
    Text("A", Modifier.weight(1f))
    Text("B", Modifier.weight(1f))
}
// 2f 和 1f 就是 2:1

4padding：內距

Compose 只有 padding，沒有 margin。padding 在元件外圍加空白，至於算內距還是外距，取決於它在串列中的位置（下一節）。

Modifier.padding(16.dp)                         // 四邊
Modifier.padding(horizontal = 16.dp)            // 左右
Modifier.padding(vertical = 8.dp)               // 上下
Modifier.padding(start = 8.dp, top = 4.dp)      // 指定邊

5順序很重要

Modifier 是由外往內一層一層套上去的。同樣是 padding 和 background，順序不同結果就不同：

// A：先加背景再加 padding → 背景比較大，文字和邊緣有距離（padding 像內距）
Modifier.background(Color.Yellow).padding(16.dp)

// B：先加 padding 再加背景 → 背景只包住文字，外面多一圈透明空白（padding 像外距）
Modifier.padding(16.dp).background(Color.Yellow)
小技巧
想要「有顏色的按鈕形狀、文字在中間有空間」，就用 A 的順序。GyroQuiz 選項的寫法：.background(顏色, 圓角).padding(12.dp)。

6背景、圓角、邊框

import androidx.compose.foundation.background
import androidx.compose.foundation.border
import androidx.compose.foundation.shape.RoundedCornerShape
import androidx.compose.ui.graphics.Color

Box(
    modifier = Modifier
        .size(150.dp)
        .background(Color(0xFF90CAF9), RoundedCornerShape(16.dp))
        .border(6.dp, Color.Red, RoundedCornerShape(16.dp)),
    contentAlignment = Alignment.Center
) {
    Text("選項 A")
}
  • Color(0xFF90CAF9)：0xFF 是不透明度，後面 6 碼和網頁色碼一樣。
  • 也可以用內建的 Color.Red、Color.White、Color.Gray。
  • background 和 border 都可以給第二個參數「形狀」。
