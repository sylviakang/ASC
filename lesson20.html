慢慢讀

1從這堂開始做 GyroQuiz

GyroQuiz 是第 56 屆分區賽 Module1 的題目：用陀螺儀控制游標回答選擇題。接下來 32 堂會一步一步把它做完。最後的 App 有 4 個頁面：

頁面內容
首頁Logo、標題、新遊戲、遊玩紀錄
答題頁題號、進度條、時間、題目、4 個彩色選項、陀螺儀游標
結算頁答對、錯誤、時長、結束時間、再玩一次、回首頁
遊玩紀錄頁從 SQLite 讀出的每一局成績

2開場 4 件事

比賽一開始就要做好，做錯會直接扣分：

項目題本要求怎麼做錯了扣
App 名稱QXX（XX 是選手編號）New Project 的 Name 填 Q051 分
Package nametw.mad08.gyroquizXXNew Project 的 Package name1 分
直向畫面固定直向AndroidManifest.xml 加一行—
素材logo.png、Questions.json放進 drawable 與 assets整個功能做不出來
補充
講義一律用選手編號 00：App 名稱 Q00、Package name tw.mad08.gyroquiz00。練習時換成自己的編號也可以。

3鎖定直向

打開 app/manifests/AndroidManifest.xml，在 <activity 那一段加上 android:screenOrientation="portrait"：

AndroidManifest.xml（只加一行）
        <activity
            android:name=".MainActivity"
            android:exported="true"
            android:screenOrientation="portrait"
            android:theme="@style/Theme.Q00">
小技巧
加了之後 Android Studio 可能會出現黃色提示（建議不要鎖方向），比賽題本要求鎖定，忽略它即可。

4assets 資料夾

圖片放 drawable，但 Questions.json 是「原封不動要讀出來的檔案」，要放在 assets。新專案預設沒有這個資料夾：

  1. 左邊專案視窗在 app 上按右鍵 → New → Folder → Assets Folder。
  2. 直接按 Finish。會出現 app/src/main/assets。
  3. 把 Questions.json 複製貼上到 assets。
注意
檔名大小寫要和程式一致。題目給的是 Questions.json（Q 大寫），之後程式也要寫 "Questions.json"。

5檔案規劃

一個檔案放一個頁面，找東西比較快。完成時的專案會長這樣（今天只建前兩個）：

完成時的檔案
tw.mad08.gyroquiz00
├─ MainActivity.kt     setContent → GyroQuizApp()
├─ App.kt              換頁（第 22 堂）
├─ HomeScreen.kt       首頁（第 21 堂）
├─ Common.kt           共用的返回列（第 23 堂）
├─ QuizScreen.kt       答題頁
├─ ResultScreen.kt     結算頁
├─ RecordsScreen.kt    遊玩紀錄頁
├─ Question.kt         題目與讀檔
├─ Formats.kt          時間格式
├─ QuizLogic.kt        計算用的小函式
└─ RecordDb.kt         SQLite

6MainActivity 只留一行畫面

範本的主題函式名稱會依專案名稱產生：Name 填 Q00，主題就叫 Q00Theme。我們保留它，裡面只呼叫 GyroQuizApp：

MainActivity.kt
package tw.mad08.gyroquiz00

import android.os.Bundle
import androidx.activity.ComponentActivity
import androidx.activity.compose.setContent
import androidx.activity.enableEdgeToEdge
import tw.mad08.gyroquiz00.ui.theme.Q00Theme

class MainActivity : ComponentActivity() {
    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        enableEdgeToEdge()
        setContent {
            Q00Theme {
                GyroQuizApp()
            }
        }
    }
}
