1C# 陣列 vs Kotlin 的 Array 與 List

C# 用 int[]；Kotlin 有 Array，但實際上最常用的是 List。GyroQuiz 全部用 List。

C#
int[] scores = { 80, 95, 72 };
Console.WriteLine(scores[0]);
Console.WriteLine(scores.Length);
Kotlin
val scores = listOf(80, 95, 72)
println(scores[0])
println(scores.size)
C#Kotlin
長度.Length.size
取第 i 個a[i]a[i]
最後一個索引a.Length - 1a.lastIndex
全部索引—a.indices（等於 0 until size）

2listOf：不能改內容

listOf 建立的 List 不能新增、刪除、修改元素，適合固定資料，例如顏色清單、選項字母。

val letters = listOf("A", "B", "C", "D")
println(letters[2])      // C
// letters[0] = "Z"      // 錯誤：不能改

3mutableListOf：可以增減

需要一直加資料時用 mutableListOf，像 C# 的 List<T>：

C#
var list = new List<int>();
list.Add(5);
list.Add(8);
list[0] = 6;
list.RemoveAt(1);
Console.WriteLine(list.Count);
Kotlin
val list = mutableListOf<Int>()
list.add(5)
list.add(8)
list[0] = 6
list.removeAt(1)
println(list.size)
補充
list 本身用 val 就可以：val 的意思是「這個變數不會換成另一個 List」，但 List 裡面的內容還是能增減。

4走訪的三種寫法

val options = listOf("貓", "狗", "魚", "鳥")

for (o in options) println(o)                 // 1. 只要值，等於 C# foreach

for (i in options.indices) println("$i: ${options[i]}")   // 2. 要索引

for ((i, o) in options.withIndex()) println("$i: $o")     // 3. 索引和值都要
注意
用 for (i in 0..options.size) 會多跑一次，取到 options[4] 而閃退。要用 indices 或 0 until size。

5常用的查詢

val nums = listOf(3, 8, 1, 8)
println(nums.contains(8))   // true，也可以寫 8 in nums
println(nums.indexOf(8))    // 1（第一個 8 的位置，找不到是 -1）
println(nums.sum())         // 20
println(nums.max())         // 8
println(nums.isEmpty())     // false
println(nums.first())       // 3
println(nums.last())        // 8

6Set：不重複的集合

GyroQuiz 要記「答錯過哪幾題」，同一題錯兩次只能算一次。mutableSetOf 會自動忽略重複的值：

val wrong = mutableSetOf<String>()
wrong.add("q3")
wrong.add("q7")
wrong.add("q3")        // 已經有了，不會再加
println(wrong.size)    // 2
