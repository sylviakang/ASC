返回列與返回鍵

三個頁面都需要左上角的返回按鈕，寫一次共用元件 BackBar 就好。另外使用者也可能按手機本身的返回鍵，預設會直接關掉 App，要用 BackHandler 攔下來，讓它和畫面上的返回按鈕做一樣的事。

觀念講解

慢慢讀

1每頁都要的返回列

答題頁、結算頁、紀錄頁的左上角都有「返回」按鈕（各 0.5 分）。三頁一樣的東西，照第 19 堂寫成共用元件，放在 Common.kt：

Common.kt
package tw.mad08.gyroquiz00

import androidx.compose.foundation.layout.Row
import androidx.compose.foundation.layout.fillMaxWidth
import androidx.compose.foundation.layout.padding
import androidx.compose.material3.Text
import androidx.compose.material3.TextButton
import androidx.compose.runtime.Composable
import androidx.compose.ui.Alignment
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import androidx.compose.ui.unit.sp

// 共用的上方列：返回按鈕 + 標題（不用圖示套件，用文字箭頭）
@Composable
fun BackBar(title: String, onBack: () -> Unit) {
    Row(
        modifier = Modifier.fillMaxWidth().padding(4.dp),
        verticalAlignment = Alignment.CenterVertically
    ) {
        TextButton(onClick = onBack) { Text("‹ 返回", fontSize = 18.sp) }
        Text(title, fontSize = 20.sp)
    }
}
補充
題本可能要求返回「圖示」。比賽只能用原生套件時，用文字 ‹ 最保險，不需要額外的圖示套件。

2手機的返回鍵

螢幕上的返回按鈕你可以控制，但使用者也可能按手機本身的返回鍵（或從邊緣往內滑）。預設行為是直接關掉 App，這不是我們要的。

BackHandler 可以攔截返回鍵，改成執行你給的程式：

import androidx.activity.compose.BackHandler

@Composable
fun RecordsScreen(onBack: () -> Unit) {
    BackHandler { onBack() }     // 按手機返回鍵 = 按畫面上的返回
    …
}
  • BackHandler 寫在頁面函式裡，只有那一頁顯示時才有作用。
  • 首頁不寫，按返回鍵就照預設關掉 App，這是正常的。

4套用到三頁

RecordsScreen.kt
@Composable
fun RecordsScreen(onBack: () -> Unit) {
    BackHandler { onBack() }
    Column(Modifier.fillMaxSize()) {
        BackBar(title = "遊玩紀錄", onBack = onBack)
        Text("尚無紀錄", modifier = Modifier.padding(24.dp))
    }
}
ResultScreen.kt
@Composable
fun ResultScreen(onPlayAgain: () -> Unit, onHome: () -> Unit) {
    BackHandler { onHome() }
    Column(Modifier.fillMaxSize()) {
        BackBar(title = "結算", onBack = onHome)
        Column(
            modifier = Modifier.fillMaxSize(),
            horizontalAlignment = Alignment.CenterHorizontally,
            verticalArrangement = Arrangement.Center
        ) {
            Button(onClick = onPlayAgain, modifier = Modifier.width(220.dp)) {
                Text("再玩一次", fontSize = 20.sp)
            }
            Spacer(Modifier.height(16.dp))
            OutlinedButton(onClick = onHome, modifier = Modifier.width(220.dp)) {
                Text("回首頁", fontSize = 20.sp)
            }
        }
    }
}
