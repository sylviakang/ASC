1題本要求

游標只能在選項區裡移動，不可以超出邊界。

2clamp：夾住

把一個數字「夾」在最小值和最大值之間：小於最小就用最小，大於最大就用最大，中間的不動。

QuizLogic.kt
// 把值限制在 min～max 之間
fun clamp(value: Float, min: Float, max: Float): Float =
    if (value < min) min else if (value > max) max else value
valueminmax結果

C / C#
float Clamp(float v, float min, float max) {
    if (v < min) return min;
    if (v > max) return max;
    return v;
}
Kotlin
fun clamp(value: Float, min: Float, max: Float) =
    if (value < min) min
    else if (value > max) max
    else value
補充
Kotlin 的 if 可以當成「有值的式子」，像 C 的三元運算子 ? :，所以整個函式可以寫成一行。標準函式庫其實也有 coerceIn，但自己寫一次比較懂，也能寫測試。
ClampTest.kt
class ClampTest {
    @Test
    fun clampInsideArea() {
        assertEquals(36f, clamp(-20f, 36f, 664f))
        assertEquals(300f, clamp(300f, 36f, 664f))
        assertEquals(664f, clamp(900f, 36f, 664f))
    }
}

3邊界要內縮一個半徑

游標是一個圓，cursorX 是圓心。如果圓心可以到 left，圓會有一半跑到外面。所以範圍要往內縮一個半徑：

範圍
x 範圍：left + CURSOR_RADIUS  ～  right - CURSOR_RADIUS
y 範圍：top  + CURSOR_RADIUS  ～  bottom - CURSOR_RADIUS
QuizScreen.kt
val cursorX = clamp(
    cursorPos((left + right) / 2, angleY, 0f, PX_PER_RAD),
    left + CURSOR_RADIUS, right - CURSOR_RADIUS
)
val cursorY = clamp(
    cursorPos((top + bottom) / 2, angleX, 0f, PX_PER_RAD),
    top + CURSOR_RADIUS, bottom - CURSOR_RADIUS
)

4一個小問題：卡在邊界

試試看：往右傾很多（游標卡在右邊界），然後往回傾一點點 —— 游標沒有馬上離開邊界，要往回傾比較多才會動。

原因：clamp 只限制「畫出來的位置」，angleY 還是一直累加。假設 angleY 已經多出右邊界 0.3 弧度，你要先轉回這 0.3，游標才會開始往左。

比賽題本只要求「不超出邊界」，這樣已經符合。而且下一堂的雙擊校正可以隨時把游標拉回中心，就是解決這種狀況的方法。

小技巧
如果想讓手感更好，可以在 clamp 之後把角度也「拉回」邊界上（練習 2）。這是加分項目，不是必要。
