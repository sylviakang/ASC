1想像一顆球在盤子上

把手機平放，想像螢幕上有一顆球：

手機動作陀螺儀角度變化游標應該
右邊往下壓繞 y 軸轉angleY 變大（正）往右（x 變大）
左邊往下壓繞 y 軸反轉angleY 變小（負）往左
上緣抬高（往自己傾）繞 x 軸轉angleX 變大（正）往下（y 變大）
上緣往前壓繞 x 軸反轉angleX 變小（負）往上
補充
注意交叉：左右移動（x）看 angleY，上下移動（y）看 angleX。因為「繞 y 軸轉」造成的是左右傾斜。
注意
方向如果和你預期相反，不要死背，直接在模擬器拖一下看游標往哪跑，反了就把那一軸的角度加負號。

2角度怎麼變成位置

游標位置 = 中心 + 角度 × 靈敏度：

QuizLogic.kt
// 角度換成游標位置：中心點 + (目前角度 - 校正時的角度) × 靈敏度
fun cursorPos(center: Float, angle: Float, baseAngle: Float, pxPerRad: Float): Float =
    center + (angle - baseAngle) * pxPerRad
  • center：選項區中心（上一堂算的）。
  • angle - baseAngle：從「基準角度」轉了多少。今天基準先用 0，第 44 堂雙擊校正時才會改。
  • pxPerRad：靈敏度，傾斜 1 弧度（約 57 度）移動幾 px。
const val PX_PER_RAD = 800f      // 傾斜 1 弧度（約 57 度）游標移動 800 px

傾斜 0.1 弧度（約 6 度）就移動 80 px，玩起來剛好。想要更靈敏就把數字調大。

GyroMathTest.kt（新增）
@Test
fun cursorFromAngle() {
    // 角度等於基準角時，游標在中心
    assertEquals(500f, cursorPos(500f, 0.3f, 0.3f, 800f), 0.01f)
    // 比基準多 0.1 弧度，移動 80 px
    assertEquals(580f, cursorPos(500f, 0.4f, 0.3f, 800f), 0.01f)
}

3把 GyroLab 搬進 QuizScreen

第 39 堂的程式幾乎原封不動搬過來，放在 QuizScreen 計時區塊下面：

QuizScreen.kt
// ---------- 陀螺儀：角速度積分成角度 ----------
var angleX by remember { mutableFloatStateOf(0f) }
var angleY by remember { mutableFloatStateOf(0f) }
DisposableEffect(Unit) {
    val sm = context.getSystemService(Context.SENSOR_SERVICE) as SensorManager
    val gyro = sm.getDefaultSensor(Sensor.TYPE_GYROSCOPE)
    var lastNs = 0L
    val listener = object : SensorEventListener {
        override fun onSensorChanged(e: SensorEvent) {
            if (lastNs != 0L) {
                val dt = (e.timestamp - lastNs) / 1_000_000_000f
                angleX = integrate(angleX, e.values[0], dt)
                angleY = integrate(angleY, e.values[1], dt)
            }
            lastNs = e.timestamp
        }
        override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) {}
    }
    sm.registerListener(listener, gyro, SensorManager.SENSOR_DELAY_GAME)
    onDispose { sm.unregisterListener(listener) }
}

然後算游標位置，Canvas 改畫在游標位置：

QuizScreen.kt
val cursorX = cursorPos((left + right) / 2, angleY, 0f, PX_PER_RAD)
val cursorY = cursorPos((top + bottom) / 2, angleX, 0f, PX_PER_RAD)

…
Canvas(Modifier.fillMaxSize()) {
    if (!ready) return@Canvas
    val c = Offset(cursorX - originX, cursorY - originY)
    drawCircle(Color(0xFF37474F), radius = CURSOR_RADIUS * 0.6f, center = c)
}
補充
cursorX / cursorY 不用 remember：每次 angleX、angleY 改變 → 重畫 → 重新計算，自然就是最新位置。這和第 27 堂的 val q = questions[index] 是一樣的道理。

4一秒重畫 50 次沒問題嗎

陀螺儀每秒更新約 50 次，angleX 每次改變都會讓 QuizScreen 重畫。Compose 很聰明，只會重畫用到 angle 的部分，手機完全跑得動。比賽版本就是這樣寫的。
