1今天要寫的程式

把第 2～11 堂學過的語法組合起來，寫一個文字版 GyroQuiz。它的流程和真正的 App 完全一樣，只是沒有畫面：

  1. 準備一個題庫（List<Question>）。
  2. 隨機抽 3 題。
  3. 每一題印出題號、題目、A～D 四個選項。
  4. 模擬玩家選答：選錯就記下這一題，再選下一個，直到答對。
  5. 全部答完後算出答對、錯誤題數，印出結算。
補充
「答錯過的題目算錯誤題數」正是 GyroQuiz 的規則：一題就算選錯好幾次，也只算錯一題，所以用 Set 記錄。

3先寫資料，再寫流程

寫程式的順序很重要：先定義資料（class），再寫小工具函式，最後才寫 main 的流程。比賽時也是這樣：先把 Question、GameResult 寫好，畫面才有東西可以顯示。

Lesson12.kt（上半部）
data class Question(
    val qid: String,
    val question: String,
    val options: List<String>,
    val answer: String
) {
    val answerIndex: Int
        get() = "abcd".indexOf(answer)
}

data class GameResult(val correct: Int, val wrong: Int, val durationSec: Int)

fun formatDuration(sec: Int): String = "${sec / 60}m ${sec % 60}s"

fun letter(i: Int): String = "ABCD"[i].toString()

4main 的流程

Lesson12.kt（下半部）
fun main() {
    // 1. 題庫
    val all = listOf(
        Question("q1", "1 + 1 = ?", listOf("1", "2", "3", "4"), "b"),
        Question("q2", "台灣最高的山？", listOf("雪山", "合歡山", "玉山", "阿里山"), "c"),
        Question("q3", "Kotlin 宣告不能改的變數用？", listOf("var", "val", "let", "const"), "b"),
        Question("q4", "一分鐘幾秒？", listOf("100", "30", "24", "60"), "d"),
        Question("q5", "listOf(1,2,3).size 是？", listOf("3", "2", "1", "0"), "a")
    )

    // 2. 隨機抽 3 題
    val questions = all.shuffled().take(3)

    // 3. 模擬玩家每題的選擇：第一次都選 A，選錯就再選下一個
    val wrongIds = mutableSetOf<String>()
    for ((i, q) in questions.withIndex()) {
        println("第 ${i + 1}/${questions.size} 題：${q.question}")
        for (k in q.options.indices) {
            println("  ${letter(k)}. ${q.options[k]}")
        }
        var choice = 0
        while (choice != q.answerIndex) {
            println("  選 ${letter(choice)} → 選擇錯誤")
            wrongIds.add(q.qid)
            choice++
        }
        println("  選 ${letter(choice)} → 答對！")
    }

    // 4. 結算
    val result = GameResult(
        correct = questions.size - wrongIds.size,
        wrong = wrongIds.size,
        durationSec = 731
    )
    println("答對 ${result.correct} 題，錯誤 ${result.wrong} 題，時長 ${formatDuration(result.durationSec)}")
}
第 1/3 題：一分鐘幾秒？ A. 100 B. 30 C. 24 D. 60 選 A → 選擇錯誤 選 B → 選擇錯誤 選 C → 選擇錯誤 選 D → 答對！ 第 2/3 題：1 + 1 = ? … 答對 1 題，錯誤 2 題，時長 12m 11s
小技巧
每次執行抽到的題目不同，結果也會不同。
