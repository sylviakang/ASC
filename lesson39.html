角速度變角度

陀螺儀只給「轉多快」，游標需要「轉了多少」。用「距離 = 速度 × 時間」的想法，把每一筆角速度乘上真正經過的秒數累加成角度，寫成可以測試的 integrate 函式，並認識漂移的問題。

觀念講解

慢慢讀

1從速度算出距離

國中物理：距離 = 速度 × 時間。開車時每一小段都把「這段的速度 × 這段的時間」加起來，就是總共走了多遠。

角度也一樣：轉過的角度 = 角速度 × 時間。陀螺儀每秒給我們約 50 次角速度，每次都加上「角速度 × 這次和上次相隔的秒數」：

第幾筆角速度 rad/s相隔秒數這段轉了累計角度
1———0
22.00.020.040.04
32.00.020.040.08
4-1.00.02-0.020.06
補充
這種「一小段一小段加起來」的做法，數學叫積分（integrate）。不用會微積分，記住「速度 × 時間，一直加」就好。

2寫成一個小函式

QuizLogic.kt
// 陀螺儀：角速度 (rad/s) × 經過秒數 = 轉過的角度
fun integrate(angle: Float, rate: Float, dtSec: Float): Float = angle + rate * dtSec

只有一行，但寫成函式有兩個好處：名字讓程式好讀；可以寫單元測試。

GyroMathTest.kt
@Test
fun integrateAngle() {
    // 每秒轉 2 弧度，經過 0.25 秒，轉了 0.5 弧度
    assertEquals(0.5f, integrate(0f, 2f, 0.25f), 0.0001f)
    // 反方向轉回來
    assertEquals(0.3f, integrate(0.5f, -0.4f, 0.5f), 0.0001f)
}
注意
Float 比較要給第三個參數「容許誤差」0.0001f。小數在電腦裡有誤差，0.1f + 0.2f 不一定剛好等於 0.3f（C/C# 也一樣）。

3每一筆的時間：e.timestamp

  • e.timestamp：這筆數值產生的時間，單位是奈秒（10⁻⁹ 秒），Long。
  • dt = (這次 - 上次) ÷ 1,000,000,000 → 秒。
  • 1_000_000_000f：底線只是讓數字好讀，等於 1000000000f。
  • 第一筆沒有「上次」，所以 lastNs == 0 時只記時間、不累加。
var lastNs = 0L
…
if (lastNs != 0L) {
    val dt = (e.timestamp - lastNs) / 1_000_000_000f
    angleX = integrate(angleX, e.values[0], dt)
    angleY = integrate(angleY, e.values[1], dt)
}
lastNs = e.timestamp
補充
為什麼不直接假設 dt = 0.02？因為感測器的頻率不保證固定，手機忙的時候可能隔 0.05 秒才來一筆。用真正的時間差才準，跟第 31 堂計時用 now - last 是同樣的道理。

5完整的 GyroLab

GyroLab.kt
@Composable
fun GyroLab() {
    val context = LocalContext.current
    var angleX by remember { mutableFloatStateOf(0f) }
    var angleY by remember { mutableFloatStateOf(0f) }

    DisposableEffect(Unit) {
        val sm = context.getSystemService(Context.SENSOR_SERVICE) as SensorManager
        val gyro = sm.getDefaultSensor(Sensor.TYPE_GYROSCOPE)
        var lastNs = 0L                                   // 上一筆的時間（奈秒）
        val listener = object : SensorEventListener {
            override fun onSensorChanged(e: SensorEvent) {
                if (lastNs != 0L) {
                    val dt = (e.timestamp - lastNs) / 1_000_000_000f   // 奈秒 → 秒
                    angleX = integrate(angleX, e.values[0], dt)
                    angleY = integrate(angleY, e.values[1], dt)
                }
                lastNs = e.timestamp
            }
            override fun onAccuracyChanged(sensor: Sensor?, accuracy: Int) {}
        }
        sm.registerListener(listener, gyro, SensorManager.SENSOR_DELAY_GAME)
        onDispose { sm.unregisterListener(listener) }
    }

    Column(Modifier.fillMaxSize().padding(24.dp)) {
        Text("角度（度）", fontSize = 24.sp)
        Text("x = ${"%.1f".format(Math.toDegrees(angleX.toDouble()))}°", fontSize = 32.sp)
        Text("y = ${"%.1f".format(Math.toDegrees(angleY.toDouble()))}°", fontSize = 32.sp)
        Button(onClick = { angleX = 0f; angleY = 0f }) { Text("歸零") }
    }
}

Math.toDegrees(弧度) 把弧度轉成度數，方便人看。程式內部還是用弧度。

6漂移

實體手機上，即使你把手機放回原位，角度可能不會剛好回到 0，而是慢慢偏掉。這叫漂移（drift）：每一筆都有一點點誤差，累加久了就變大。

解決方法是讓使用者自己校正 —— 這就是題本要求「雙擊校正」的原因（第 44 堂）。
