觀念講解

慢慢讀

1題本要求（答錯）

  • 選到錯誤選項：該選項顯示紅色外框，Toast「選擇錯誤」。
  • 接下來 5 秒內不能選任何選項（鎖定），游標的圓圈改成紅色倒數。
  • 5 秒後紅框消失，可以重新選。

2狀態機：用 enum 表示「現在在做什麼」

答題頁現在有三種狀態：

Phase意思停留計時外框
PLAYING正常作答有無
WRONG答錯鎖定 5 秒無紅框
CORRECT答對等 2 秒（下一堂）無綠框
enum class Phase { PLAYING, WRONG, CORRECT }

像 C 的 enum。用一個 phase 變數記錄目前狀態，比用好幾個 Boolean（isWrong、isLocked、isCorrect…）清楚很多，也不會出現「同時 true」的矛盾。這種寫法叫狀態機。

流程
PLAYING ──停滿3秒選錯──▶ WRONG ──5 秒後──▶ PLAYING
PLAYING ──停滿3秒選對──▶ CORRECT ──2 秒後──▶ 下一題（PLAYING）

3新增的狀態

  • phase：目前狀態。
  • marked：要畫外框的選項編號（-1 = 不畫）。
  • lock：鎖定剩餘比例，1 → 0，用來畫紅色倒數圈。

4停留計時加上 phase

QuizScreen.kt
enum class Phase { PLAYING, WRONG, CORRECT }        // 檔案上方、函式外

// ---------- 停留選答與答對答錯狀態 ----------
var phase by remember { mutableStateOf(Phase.PLAYING) }
var marked by remember { mutableIntStateOf(-1) }       // 顯示紅框或綠框的選項
var dwell by remember { mutableFloatStateOf(0f) }      // 停留進度 0～1
var lock by remember { mutableFloatStateOf(0f) }       // 鎖定剩餘 1～0

LaunchedEffect(hovered, phase, index) {
    dwell = 0f
    if (phase != Phase.PLAYING || hovered < 0) return@LaunchedEffect   // 鎖定中不計時
    val start = System.currentTimeMillis()
    while (dwell < 1f) {
        delay(16)
        dwell = dwellProgress(System.currentTimeMillis() - start)
    }
    if (hovered == q.answerIndex) {
        choose(hovered)                    // 答對：暫時沿用，第 49 堂改
    } else {
        marked = hovered
        wrongIds.add(q.qid)
        Toast.makeText(context, "選擇錯誤", Toast.LENGTH_SHORT).show()
        phase = Phase.WRONG
    }
}

LaunchedEffect(phase, index) {
    if (phase == Phase.WRONG) {
        val start = System.currentTimeMillis()
        while (true) {
            val passed = System.currentTimeMillis() - start
            lock = 1f - dwellProgress(passed, 5000)      // 1 → 0
            if (passed >= 5000) break
            delay(16)
        }
        marked = -1
        phase = Phase.PLAYING
    }
}
  1. 停留計時的 key 多了 phase；開頭 phase != Phase.PLAYING 就不計時 → 鎖定時游標怎麼移都不會選。
  2. 選錯：記 marked、加錯題、Toast、phase = WRONG。
  3. 第二個 LaunchedEffect 監看 phase：一進 WRONG 就跑 5 秒倒數（重用 dwellProgress 傳 5000），結束後清掉 marked、回到 PLAYING。
  4. 回到 PLAYING 時 phase 改變 → 停留計時重新開始，所以不用移開也能重新選（解決第 46 堂的現象）。
補充
lock = 1f - dwellProgress(passed, 5000)：dwellProgress 是 0→1，用 1 減掉就是 1→0 的倒數。
