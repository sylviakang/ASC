觀念講解

慢慢讀

1Kotlin 程式從 main 開始

C# 的主控台程式從 static void Main() 開始；Kotlin 從 fun main() 開始。Kotlin 不需要先寫 class 才能寫 main，一個 .kt 檔案直接寫函式就可以。

C#
using System;

class Program
{
    static void Main()
    {
        Console.WriteLine("Hello");
    }
}
Kotlin
fun main() {
    println("Hello")
}
  • fun 是「函式（function）」的意思，等於 C# 的 void 或回傳型別那個位置。
  • println 印出一行並換行，等於 Console.WriteLine；print 不換行，等於 Console.Write。
  • 句尾不用分號。寫了也不會錯，但 Kotlin 的習慣是不寫。

2在 Android Studio 執行 Kotlin 檔

比賽只能用 Android Studio，所以 Kotlin 基礎也在 Android Studio 裡練。我們開一個練習專案，在裡面新增純 Kotlin 檔案：

  1. New Project → Empty Activity，Name 填 KotlinPractice，Package name 填 tw.mad08.practice。
  2. 左邊專案視窗展開 kotlin+java，在 tw.mad08.practice 上按右鍵 → New → Kotlin Class/File。
  3. 在跳出的小視窗選 File，名稱打 Lesson02，按 Enter。
  4. 在檔案裡寫 fun main()，左邊行號旁會出現綠色三角形 ▶，按它選 Run 'Lesson02Kt'。
  5. 結果顯示在下方的 Run 視窗。
補充
這種檔案只在電腦上執行，不會裝到手機上，所以不用開模擬器。第 2～12 堂都用這個方法練習，每堂一個檔案：Lesson03.kt、Lesson04.kt……
小技巧
同一個專案裡可以有很多個檔案都有 main，按哪一個檔案的 ▶ 就執行哪一個。

3程式由上往下一行一行執行

fun main() {
    println("第一行")
    println("第二行")
    print("同一行 ")
    print("接著寫")
    println()            // 只換行
    println("最後一行")
}
第一行 第二行 同一行 接著寫 最後一行

4註解

和 C# 完全一樣：// 註解到行尾，/* … */ 註解一整段。Android Studio 裡選取幾行按 Ctrl + / 可以一次加上或取消註解。

// 這是單行註解
/*
  這是多行註解
  比賽時可以用註解標記每一段在做什麼
*/
fun main() {
    println("Hi")   // 行尾也可以寫註解
}

5大小寫與括號

  • Kotlin 大小寫有別：println 寫成 Println 會出現紅字。
  • 大括號 { } 一定要成對；Android Studio 打 { 按 Enter 會自動補上 }。
  • 字串用雙引號 "…"；單引號 'A' 只能放一個字元。
注意
看到紅色波浪底線先不要慌：把滑鼠移上去讀訊息，常見的是 Unresolved reference（名字打錯）和 Expecting '}'（少了大括號）。
