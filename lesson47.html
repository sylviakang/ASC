觀念講解

慢慢讀

1題本要求

停留時，在游標周圍顯示圓形進度，3 秒畫滿一圈。

2drawArc 的參數

drawArc(color, startAngle, sweepAngle, useCenter, topLeft, size, style = Stroke(寬))
參數意思我們用
startAngle從哪個角度開始（度）。0 度是 3 點鐘方向，順時針為正-90f（12 點鐘）
sweepAngle畫多少度360f * dwell
useCentertrue 畫成扇形（披薩），false 只有弧線false
topLeft, size圓弧所在的「外接正方形」以游標為中心、邊長 2R
styleStroke(寬度) 只畫線；不寫就是填滿Stroke(8f)
角度方向
          -90°（12 點）
             │
 180° ───────┼─────── 0°（3 點）
             │
           90°（6 點）
 順時針為正（因為 y 往下）
WinForms
e.Graphics.DrawArc(pen,
    cx - r, cy - r, 2 * r, 2 * r,
    -90, 360 * progress);
Compose
drawArc(color, -90f, 360f * dwell, false,
    Offset(cx - r, cy - r), Size(2 * r, 2 * r),
    style = Stroke(8f))

剛好和 WinForms 的 DrawArc 幾乎一樣：都是用外接矩形 + 起點角 + 掃過角。

3外接正方形

圓心是 c、半徑 R，外接正方形左上角 = (c.x - R, c.y - R)，大小 = (2R, 2R)。

實心圓用 0.6R，進度圈用 R，兩者之間留了一圈空隙，看起來像準星。

4今天的 Canvas

QuizScreen.kt
Canvas(Modifier.fillMaxSize()) {
    if (!ready) return@Canvas
    val c = Offset(cursorX - originX, cursorY - originY)
    drawCircle(Color(0xFF37474F), radius = CURSOR_RADIUS * 0.6f, center = c)
    if (dwell > 0f) {
        val ringSize = Size(CURSOR_RADIUS * 2, CURSOR_RADIUS * 2)
        val ringTopLeft = Offset(c.x - CURSOR_RADIUS, c.y - CURSOR_RADIUS)
        drawArc(
            Color(0xFF1565C0),        // 顏色
            -90f,                     // 起點角度：12 點鐘方向
            360f * dwell,             // 掃過的角度
            false,                    // 不連到圓心（不是扇形）
            ringTopLeft, ringSize,    // 圓弧所在的正方形
            style = Stroke(8f)        // 只畫線，寬 8px
        )
    }
}

補充
為什麼進度圈會動？dwell 每 16 毫秒改變 → 重畫 → Canvas 重新畫一次。沒有寫任何「動畫」程式，狀態改變自然就動起來了。
