觀念講解

慢慢讀

1class：和 C++、C# 很像

你學過 C/C++ 的 struct 和 class：把相關的資料（和函式）包在一起。Kotlin 的 class 最大的不同是：建構子直接寫在類別名稱後面。

C#
class Student
{
    public string Name;
    public int Score;

    public Student(string name, int score)
    {
        Name = name;
        Score = score;
    }
}

var s = new Student("Amy", 90);
Kotlin
class Student(val name: String, var score: Int)



val s = Student("Amy", 90)
  • 括號裡的 val name、var score 同時是建構子參數和屬性，一行就宣告完。
  • 建立物件不用寫 new。
  • 取屬性用點：s.name、s.score。

2加上方法

方法寫在大括號裡，和一般函式一樣：

class Student(val name: String, var score: Int) {
    fun isPass(): Boolean = score >= 60
    fun addBonus(n: Int) {
        score += n
    }
}

val s = Student("Amy", 55)
println(s.isPass())   // false
s.addBonus(10)
println(s.score)      // 65
println(s.isPass())   // true

3屬性也可以是算出來的

有些屬性不用存，用 get() 每次需要時算出來。GyroQuiz 的題目存的是答案字母 "c"，但程式要的是索引 2：

class Question(val question: String, val answer: String) {
    val answerIndex: Int
        get() = "abcd".indexOf(answer)
}

val q = Question("1+1=?", "b")
println(q.answerIndex)   // 1
補充
"abcd".indexOf("b") 找出 "b" 在字串 "abcd" 的位置，剛好就是 0～3。

4data class：專門裝資料的類別

很多類別只是用來裝資料，像 C 的 struct。在 class 前面加 data，Kotlin 會自動幫你做好：印出內容、比較兩個物件是否相等、複製。

data class GameResult(val correct: Int, val wrong: Int, val durationSec: Int)

val a = GameResult(8, 2, 300)
val b = GameResult(8, 2, 300)
println(a)          // GameResult(correct=8, wrong=2, durationSec=300)
println(a == b)     // true（內容一樣就相等）
val c = a.copy(wrong = 3)
println(c)          // GameResult(correct=8, wrong=3, durationSec=300)
小技巧
如果拿掉 data，println(a) 只會印出一串看不懂的記憶體位置，a == b 也會是 false。

5物件放進 List

val records = mutableListOf<GameResult>()
records.add(GameResult(8, 2, 300))
records.add(GameResult(10, 0, 250))
for (r in records) {
    println("答對 ${r.correct}，用了 ${r.durationSec} 秒")
}

這就是 GyroQuiz「遊玩紀錄」的資料形狀：一個 List，每一筆是一個 GameResult。
