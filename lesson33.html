2把四個數字包成一個 data class

答題頁要把 4 個值交給結算頁。與其傳 4 個參數，不如包成一個 data class（第 9 堂），就像 C 的 struct：

QuizLogic.kt
data class GameResult(
    val correct: Int,
    val wrong: Int,
    val durationSec: Int,
    val endMillis: Long
)
C
struct GameResult {
    int correct, wrong, durationSec;
    long long endMillis;
};
Kotlin
data class GameResult(
    val correct: Int, val wrong: Int,
    val durationSec: Int, val endMillis: Long)

endMillis 存「結束時間的毫秒數」（System.currentTimeMillis()），要顯示時再轉格式。存數字比存字串好：之後資料庫可以用它排序。

3onFinish 帶參數

以前 onFinish: () -> Unit 是「沒有參數的函式」。現在要把成績交出去，改成：

onFinish: (GameResult) -> Unit       // 收一個 GameResult 的函式

答題頁最後一題答對時：

QuizScreen.kt choose()
onFinish(
    GameResult(
        correct = questions.size - wrongIds.size,
        wrong = wrongIds.size,
        durationSec = (elapsedMs / 1000).toInt(),
        endMillis = System.currentTimeMillis()
    )
)

App.kt 收到後存起來、換頁：

onFinish = { r ->
    result = r
    screen = Screen.RESULT
}
補充
{ r -> … }：r 就是答題頁傳過來的 GameResult。這和 C# 的 r => { … } 一樣。

4result 為什麼是 GameResult?

mutableStateOf<GameResult?>(null)：一開始還沒玩過，沒有成績，所以是 null（第 10 堂）。結算頁用 if (result != null) 檢查後才顯示。

5時長與日期的格式

Formats.kt
fun two(n: Int) = n.toString().padStart(2, '0')

// 答題經過時間 mm:ss
fun formatClock(totalSec: Int) = "${two(totalSec / 60)}:${two(totalSec % 60)}"

// 答題時長 12m 11s
fun formatDuration(totalSec: Int) = "${totalSec / 60}m ${totalSec % 60}s"

// 答題結束日期時間 2026.06.26 05:45 PM
fun formatEndTime(millis: Long): String =
    SimpleDateFormat("yyyy.MM.dd hh:mm a", Locale.US).format(Date(millis))
  • formatDuration(731) → 731/60 = 12、731%60 = 11 → "12m 11s"（題本格式不用補 0）。
  • SimpleDateFormat 和 C# 的 ToString("yyyy.MM.dd hh:mm tt") 很像：
符號意思注意
yyyy西元年
MM月（兩位）大寫！小寫 mm 是分鐘
dd日
hh12 小時制的時HH 是 24 小時制
mm分
aAM / PM
注意
Locale.US 一定要加。手機語言是中文時，a 會變成「下午」而不是 PM，不符合題本。
FormatsTest.kt
package tw.mad08.gyroquiz00

import org.junit.Assert.assertEquals
import org.junit.Test
import java.util.Calendar

class FormatsTest {
    @Test
    fun duration() {
        assertEquals("12m 11s", formatDuration(731))
        assertEquals("0m 59s", formatDuration(59))
    }

    @Test
    fun endTime() {
        val c = Calendar.getInstance()
        c.set(2026, Calendar.JUNE, 26, 17, 45, 0)
        assertEquals("2026.06.26 05:45 PM", formatEndTime(c.timeInMillis))
        c.set(2026, Calendar.DECEMBER, 1, 0, 3, 0)
        assertEquals("2026.12.01 12:03 AM", formatEndTime(c.timeInMillis))
    }
}

ResultScreen.kt
@Composable
fun ResultScreen(result: GameResult?, onPlayAgain: () -> Unit, onHome: () -> Unit) {
    BackHandler { onHome() }
    Column(Modifier.fillMaxSize()) {
        BackBar(title = "結算", onBack = onHome)
        Column(
            modifier = Modifier.fillMaxSize().padding(24.dp),
            horizontalAlignment = Alignment.CenterHorizontally,
            verticalArrangement = Arrangement.Center
        ) {
            if (result != null) {
                Text("答對題數：${result.correct}", fontSize = 24.sp)
                Text("錯誤題數：${result.wrong}", fontSize = 24.sp)
                Text("答題時長：${formatDuration(result.durationSec)}", fontSize = 24.sp)
                Text("結束時間：${formatEndTime(result.endMillis)}", fontSize = 20.sp)
            }
            Spacer(Modifier.height(40.dp))
            Button(onClick = onPlayAgain, modifier = Modifier.width(220.dp)) {
                Text("再玩一次", fontSize = 20.sp)
            }
            Spacer(Modifier.height(16.dp))
            OutlinedButton(onClick = onHome, modifier = Modifier.width(220.dp)) {
                Text("回首頁", fontSize = 20.sp)
            }
        }
    }
}

返回列、返回鍵、回首頁都回首頁；再玩一次直接回答題頁（重新抽題，因為 QuizScreen 是重新建立的）。
