觀念講解

慢慢讀

1交件前先整理

比賽交的是 APK 檔（安裝檔）和專案。匯出前先把測試用的東西清掉：

要檢查的怎麼找處理
偷看答案、角度顯示等測試畫面Ctrl+Shift+F 搜尋 TODO、"答案"刪除
take(10) 有沒有被改成 take(2)搜尋 take(改回 10
MainActivity 是否呼叫 GyroQuizApp打開 MainActivity不是 GyroLab
Log.d搜尋 Log.d可留（不影響使用者），想刪也可以
App 名稱、套件名稱strings.xml app_name、build.gradle applicationId符合題本編號

2跑一次全部的單元測試

在 app/src/test/java/套件 資料夾按右鍵 → Run 'Tests in …'。ColorTest、ClockTest、FormatsTest、GyroMathTest、ClampTest、HitTest 應該全部綠色。

3乾淨安裝測試

你的模擬器上有很多舊資料。評審拿到的是全新安裝，所以要模擬一次：

  1. 長按 App 圖示 → 解除安裝（或 應用程式資訊 → 清除儲存空間）。
  2. 重新 Run。
  3. 依序檢查：首頁 → 遊玩紀錄（應該是「尚無紀錄」）→ 新遊戲 → 玩完 → 結算 → 遊玩紀錄有一筆。
注意
最常見的扣分：資料庫在你的電腦上沒問題，因為表早就建好了；乾淨安裝時 onCreate 的 SQL 打錯就閃退。一定要做這一步。

4匯出 APK

新版 Android Studio：

  1. 選單 Build → Generate App Bundles or APKs → Generate APKs。
  2. 等右下角出現 APK(s) generated successfully，按 locate。
  3. 檔案在 app/build/outputs/apk/debug/app-debug.apk。

舊版 Android Studio 的選單是 Build → Build Bundle(s) / APK(s) → Build APK(s)，結果一樣。

補充
debug 版 APK 用 Android Studio 自動產生的測試簽章，可以直接安裝。題本若沒有要求正式簽章（Generate Signed…），用 debug 版即可。

依題本規定改檔名（例如 Q00.apk），放到指定的資料夾。

5把 APK 裝到模擬器驗證

把 apk 檔直接拖曳到模擬器視窗就會安裝。裝好後從桌面點圖示打開（不是用 Run），確認能正常執行。

6交件檢查表

  • APK 檔名、位置符合題本
  • 專案資料夾完整（可以壓縮成 zip）
  • 乾淨安裝測試通過
  • 單元測試全部通過
  • 沒有測試用的畫面或改過的數字
小技巧
比賽最後 15 分鐘不要再加新功能。先匯出一份能用的 APK 存好，有時間再改，改完再匯出覆蓋。
