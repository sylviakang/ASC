觀念講解

慢慢讀

1為什麼要量位置

之後要做兩件事都需要知道「選項在螢幕上的哪裡」：

  1. 游標一開始要在選項區中心，而且不能跑出選項區（第 42、43 堂）。
  2. 判斷游標停在哪一個選項上（第 45 堂）。

但選項大小是 weight 自動分配的，不同手機不一樣，寫死數字一定錯。所以要讓 Compose 排好版之後告訴我們每格的位置。

2onGloballyPositioned：排好版之後通知你

Modifier.onGloballyPositioned { coords ->
    val b = coords.boundsInRoot()     // 這個元件在整個畫面的位置（px）
    // b.left, b.top, b.right, b.bottom
}

像 WinForms 讀控制項的 Left / Top / Right / Bottom，只是 Compose 要等排版完成才知道，所以用「通知」的方式拿到。

屬性意思
b.left / b.right左邊、右邊的 x
b.top / b.bottom上緣、下緣的 y
positionInRoot()左上角那一點 (x, y)

3存起來：4 格的矩形

每格存成 floatArrayOf(left, top, right, bottom)，4 格放在一個 List 裡。一開始還沒量到，所以放 4 個 null：

val rects = remember { mutableStateListOf<FloatArray?>(null, null, null, null) }
  • mutableStateListOf：會觸發重畫的 List（像 mutableStateOf，但是一整個清單）。
  • FloatArray?：可能是 null 的 float 陣列。
  • 在第 i 格的 Modifier 裡寫 rects[i] = r。
注意
只在位置改變時才寫入：if (rects[i]?.contentEquals(r) != true) rects[i] = r。如果每次都寫入，寫入 → 重畫 → 又量到 → 又寫入……會一直重畫停不下來。contentEquals 比較兩個陣列的內容是否一樣。

4算出選項區的範圍

QuizScreen.kt
// ---------- 選項位置 ----------
val rects = remember { mutableStateListOf<FloatArray?>(null, null, null, null) }
var originX by remember { mutableFloatStateOf(0f) }
var originY by remember { mutableFloatStateOf(0f) }
val ready = rects.all { it != null }                     // 4 格都量好了嗎
val left = if (ready) rects.minOf { it!![0] } else 0f
val top = if (ready) rects.minOf { it!![1] } else 0f
val right = if (ready) rects.maxOf { it!![2] } else 0f
val bottom = if (ready) rects.maxOf { it!![3] } else 0f
  • rects.all { it != null }：4 格都量好才算 ready。
  • 選項區的左邊 = 4 格裡最小的 left；右邊 = 最大的 right，上下同理。
  • it!![0]：!! 是「我保證不是 null」。前面已經檢查 ready，所以安全。

選項區中心就是 ((left + right) / 2, (top + bottom) / 2)。

5座標要扣掉 origin

boundsInRoot 是相對於整個畫面（root）的座標；Canvas 的 (0, 0) 卻是Canvas 自己的左上角。因為 App 有 safeDrawingPadding（避開狀態列），兩者差了一段：

示意
畫面頂端 (root y = 0)
 ┌────────── 狀態列 ──────────┐
 │                             │ ← 差 originY
 ├─ 外層 Box / Canvas 的 (0,0) ┤
 │   …                         │

所以畫的時候要減掉外層 Box 的位置：x - originX、y - originY。

QuizScreen.kt
Box(
    modifier = Modifier
        .fillMaxSize()
        .onGloballyPositioned {                       // 新增：量出外層 Box 的左上角
            originX = it.positionInRoot().x
            originY = it.positionInRoot().y
        }
) {
    Column(…) { … }

    Canvas(Modifier.fillMaxSize()) {
        if (!ready) return@Canvas                     // 還沒量好就先不畫
        val c = Offset((left + right) / 2 - originX, (top + bottom) / 2 - originY)
        drawCircle(Color(0xFF37474F), radius = CURSOR_RADIUS * 0.6f, center = c)
    }
}

6選項 Box 加上量測

QuizScreen.kt
Box(
    modifier = Modifier
        .weight(1f)
        .fillMaxSize()
        .background(OptionPalette[colors[i]], RoundedCornerShape(16.dp))
        .clickable { choose(i) }
        .onGloballyPositioned {                       // 新增：量出這一格的位置
            val b = it.boundsInRoot()
            val r = floatArrayOf(b.left, b.top, b.right, b.bottom)
            if (rects[i]?.contentEquals(r) != true) rects[i] = r
        }
        .padding(12.dp),
    contentAlignment = Alignment.Center
) { … }
補充
onGloballyPositioned 放在 padding 前面，量到的才是整個色塊，而不是扣掉留白的內部。
