變數與型別

程式要記住資料就需要變數。C# 是「型別 名字 = 值」，Kotlin 是「val 或 var 名字 = 值」，型別大多可以省略。這堂把 GyroQuiz 會用到的 7 種型別一次認識。

可以改var score = 0
寫型別val speed: Float = 1.5f

觀念講解

慢慢讀

1val 和 var

C# 宣告變數要先寫型別：int score = 0;。Kotlin 用兩個關鍵字開頭：

  • val（value）：不能再改的變數，等於 C# 的 readonly 或 const 的感覺。
  • var（variable）：可以再改的變數。
C#
int score = 0;
score = 10;

const int MAX = 10;
// MAX = 20;   // 錯誤
Kotlin
var score = 0
score = 10

val max = 10
// max = 20     // 錯誤：Val cannot be reassigned
小技巧
原則：先用 val，真的需要改值時才改成 var。Android Studio 也會提示你「這個 var 從來沒改過，可以改成 val」。

2型別寫在名字後面

Kotlin 會從等號右邊的值自動推斷型別，所以通常不寫型別。要寫的話寫在名字後面，用冒號隔開。

C#
int count = 10;
float speed = 1.5f;
double pi = 3.14159;
bool ok = true;
string name = "Amy";
char grade = 'A';
Kotlin
val count: Int = 10
val speed: Float = 1.5f
val pi: Double = 3.14159
val ok: Boolean = true
val name: String = "Amy"
val grade: Char = 'A'
型別推斷
val count = 10        // 推斷為 Int
val speed = 1.5f      // 有 f → Float
val pi = 3.14159      // 小數沒有 f → Double
val ok = true         // Boolean
val name = "Amy"      // String
注意
Kotlin 的型別開頭大寫：Int、Float、Boolean、String。C# 的 bool 在 Kotlin 叫 Boolean。

3常用型別一覽

型別用途例子GyroQuiz 會用在
Int整數10、-3題號、答對題數
Long很大的整數1700000000000L時間（毫秒）
Float小數（精度較低，結尾加 f）1.5f游標座標、進度 0～1
Double小數（精度高）3.14平均分數

補充
Android 的畫面座標大多用 Float，所以你會常常看到數字後面有 f，例如 36f。

4宣告後一定要有值

C# 的區域變數沒給值就使用會出錯；Kotlin 也一樣，而且更嚴格：宣告時通常就要給值。

var total: Int      // 先宣告型別
total = 0           // 再給值，可以
println(total)

val x = 5
x = 6               // 錯誤：val 不能改

5型別不能混著放

Kotlin 不會偷偷幫你轉型。Int 的變數不能放小數，也不能把 Int 直接指定給 Float 變數。

var a = 10
a = 2.5            // 錯誤：Type mismatch
var f: Float = 10  // 錯誤：10 是 Int
var g: Float = 10f // 正確
